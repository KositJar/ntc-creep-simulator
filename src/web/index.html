How to Use

1. Enter the password

Use the lab password to access the simulator.

2. Set parameters

The Parameter Editor is pre-loaded with the SL1T60 example. Expand any section to edit values. Click Browse to upload a .prm file, or Export .prm to save your current values.

3. Define the loading sequence

The Loading Sequence table uses the simplified .sctr format (4 columns). Add/remove rows with the buttons. Upload an existing .sctr file or export to save your sequence.

4. Run the simulation

Click Run Simulation. The progress bar shows the percentage of total simulation time completed. When done, results appear as a chart.

5. Interpret results

Default chart: irreversible strain (ep_ir) on X-axis vs stress ratio R = Sigma (solid) and Sigma_f (dashed) on Y-axis. Both stress components are offset by +1 to reflect R = σ₁'/σ₃' starting from 1 at isotropic state. Use the axis selectors to switch to any other output column.

6. Download

Click ⬇ Download .dat to save the raw tab-separated output for post-processing in MATLAB or Excel.

FAQ

What is the NTC model?

The Nonlinear Three-Component (NTC) model decomposes soil deformation into elastic, inviscid (plastic), and viscous (creep) components. It was developed by Di Benedetto et al. and Tatsuoka et al. (2002) and is widely used for time-dependent behaviour of geomaterials.

What does Sigma represent?

Sigma is the stress ratio R = σ₁'/σ₃' (major to minor effective principal stress). In the output file it starts from 0 (= isotropic, R = 1), so +1 is added for display.

What is ep_ir?

ep_ir is the irreversible (plastic + creep) strain. Together with Sigma it forms the primary stress-strain curve.

What is tau?

τ is the creep damage variable. It tracks accumulated viscous deformation history.

How do I run the original 3Comp desktop program?

Download the 3Comp_modern_v2 repository from GitHub and build with Visual Studio 2022.

Why does the progress bar show a percentage?

Progress is calculated as currentTime / totalSimulationTime × 100. The simulation runs in a Web Worker so the browser stays responsive throughout.

Can I change the password?

Yes — see the About section for instructions.

About

NTC Creep Simulator v1.5

Developed by Kosit Jariyatatsakorn

A browser-based interface for the Nonlinear Three-Component (NTC) constitutive model for geomaterials. The C++ model is compiled to WebAssembly via Emscripten and runs entirely in the browser.

References

  • Di Benedetto, H., Tatsuoka, F., & Ishihara, M. (2002). Time-dependent shear deformation characteristics of sand and their constitutive modelling. Soils and Foundations, 42(2), 1–22.
  • Tatsuoka, F., Ishihara, M., Di Benedetto, H., & Kuwano, R. (2002). Time-dependent shear deformation characteristics of geomaterials and their simulation. Soils and Foundations, 42(2), 103–129.

Changing the password

Open src/web/app.js and replace PASSWORD_HASH with the SHA-256 hash of your new password. To get the hash, run this in any browser console:

crypto.subtle.digest("SHA-256", new TextEncoder().encode("yourpassword"))
  .then(b => console.log(Array.from(new Uint8Array(b))
    .map(x=>x.toString(16).padStart(2,"0")).join("")))

Then push to main — GitHub Actions will rebuild and redeploy automatically.
